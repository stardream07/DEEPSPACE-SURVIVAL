# Dependencies

The Java source, pixel sprites, palette, and bitmap alphabet in this project are original work. The reference image was inspected for visual direction and is not redistributed with the project.

JavaFX 21.0.5 (`javafx-base`, `javafx-graphics`, and `javafx-controls`) is provided by [OpenJFX](https://openjfx.io/) under the [GNU General Public License v2 with the Classpath Exception](https://github.com/openjdk/jfx/blob/jfx21/LICENSE). Runtime module jars downloaded from Maven Central are stored in `.deps/` for local use. On other platforms, `setup.sh` downloads matching native modules or Maven resolves them automatically.

Java itself is supplied by the host system and is not bundled.
